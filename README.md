Title : Food delivary App
MealDrop Application
MealDrop is a mobile application designed for seamless food ordering and delivery. The app features a simple user interface that allows users to log in, explore categorized food menus, place orders, choose payment options, and track order confirmation.

Key Features
User Authentication: Multi-option login including third-party OAuth (Google).
Dynamic Menu Display: Structured meal categories (Daily Specials, Fast Food, Burgers, Snacks, Meal Slots).
Streamlined Checkout: Fast payment options for both cash and online methods.
Order Tracking Status: Clear feedback screens for order confirmation.
